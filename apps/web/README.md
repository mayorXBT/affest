# Affest dashboard

Next.js App Router control room for Affest. Connect an injected wallet to
Creditcoin CC3 Testnet. No private keys are collected.

```powershell
pnpm --filter @affest/web dev
```

Opens http://localhost:3000. Sample vault data appears only after **Use preview wallet**.

Identity: Affest. Tagline: Verified cross-chain automation for self-driving portfolios.
Tokens live in `design-tokens.json` and `app/globals.css`.
